# Smart Restaurant Management System (SRMS)

This is a web-based Smart Restaurant Management System developed using HTML, CSS, and JavaScript. It allows users to register, make bookings, and simulate payments with proper validation.

## 🔹 Features
- User Registration System  
- Table Booking System  
- Payment form with validation (simulation only)  
- Data stored using Local Storage  
- Simple and user-friendly interface  

## 🔹 Technologies Used
- HTML  
- CSS  
- JavaScript  

## 🔹 Pages Included
- index.html (Home Page)  
- register.html  
- booking.html  
- payment.html  

## 🔹 Important Note
- The payment system in this project is **not real**.  
- It is only a **simulation for learning purposes**.  
- Real payment integration requires backend development and database (e.g., SQL, APIs).

## 🔹 Project Purpose
This project was created as a college  to understand web development concepts and simulate a restaurant booking and management system.
